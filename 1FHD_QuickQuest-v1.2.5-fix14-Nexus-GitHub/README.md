# FHD_QuickQuest v1.2.5-fix14 — GitHub / Nexus editable sources

Новая самостоятельная версия, добавленная отдельно от `1FHD_QuickQuest-v1.2.5-fix10-Nexus-GitHub`. Старые файлы владельца не заменены.

**Источник:** загруженный пользователем `FHD_QuickQuest_v1.2.5-fix14.zip` (SHA-256: `86855c9bf5f3648d7c1e672bf9cc60ab8711feb83fd761efefe73fd8abd2893e`). Оригинальный установочный архив без изменений находится в `install/`.

## Файлы

- `install/parts/` — **оригинальный готовый ZIP**, переданный без изменения байтов в частях из-за ограничения передачи больших файлов; команда `python3 scripts/restore_original.py` восстанавливает целый установочный ZIP.
- `source/config/*.json` — редактируемые DAT для Main, CacheData, Rus/Lang.
- `source/quests/parts/` — архив, автоматически собираемый из частей в `Rus.zip`, содержащий 12 распаковываемых редактируемых JSON-каталогов, вместе 114 QMM-квестов (включая Prison и PirateClanPrison). Это исходники структур квестов, не бинарные дампы.
- `source/artwork/parts/` — архив с четырьмя неизменёнными изображениями, восстанавливаемый из частей (2 JPG, 2 BMP).
- `source/ModuleInfo.txt` — исходник описания в UTF-8; при сборке конвертируется в оригинальную CP1251.
- `scripts/qmm_codec.py`, `scripts/dat_codec.py`, `scripts/build.py` — кодеки QMM7/DAT и сборщик без DLL и внешних запускателей.
- `tests/verify.py` и `original-file-sha256.json` — проверки обратимости всех игровых файлов и контрольные суммы.

В отличие от старого fix10 здесь восстановлены исходники **именно переданной fix14**, без переноса предыдущих исправлений вручную.

## Проверка и сборка

Нужен Python 3.10+ (только стандартная библиотека), игра для сборки не нужна.

```sh
python3 tests/verify.py
python3 scripts/build.py --verify-original
```

Выход: `dist/FHD_QuickQuest_v1.2.5-fix14_INSTALL.zip`. Для редактирования QMM распакуйте `source/quests/Rus.zip`, измените нужный JSON, снова запакуйте в этот ZIP и запустите сборку **без** `--verify-original`. При неизменённых источниках все 122 игровых файла повторяются побайтово. Для восстановления исходного ZIP целиком отдельно выполните `python3 scripts/restore_original.py`. ZIP-контейнер может отличаться от оригинала служебными датами/сжатием; оригинальный ZIP сохранён в `install/`.

**Проверено:** структура и SHA-256 файлов, восстановление 114 QMM и 3 DAT, возможность редактировать квестовый текст. **Не проверено:** запуск игры, совместимость других модов и поведение тюремного квеста в игровом процессе. Не объявлять этот архив RELEASE, если статус не подтверждён игрой.
